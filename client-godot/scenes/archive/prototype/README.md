# Archived prototype scenes

The earlier `island_preview.tscn` and `sculpted_terrain_preview.tscn` scenes remain in their historical paths for functional regression tests. They are not player-facing art and are not visual acceptance evidence. The player-facing graphics restart is `scenes/realistic_coastal_slice.tscn`, which uses irregular authored terrain, CC0 PBR GLTF assets, bounded water/foam, and separate gameplay/cinematic cameras.

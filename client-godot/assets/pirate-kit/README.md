# IOM-01 admitted Pirate Kit assets

This package contains four files downloaded from the publisher-linked November 2023 Quaternius Pirate Kit folder. The dated publisher announcement and pack page identify this release as CC0; the current Quaternius licence page is recorded separately because its standalone redistribution terms differ. The manifest records the exact Drive file IDs, byte counts, hashes, and dependency closure used for this admission.

The previous draft manifest named `Ship_Small.obj`, but that file is absent from the source folder. The source provides `Ship_Small.gltf`; the corrected GLTF payload is admitted here after exact hash and embedded-dependency verification.

These files are approved for Godot import validation and non-production visual integration. They do not by themselves prove final visual quality, Android performance, device thermal behavior, or gameplay integration. Any scene that uses them still requires Godot 4.7.2 import, rendered capture, Android export, mobile-cost measurement, and independent visual review.

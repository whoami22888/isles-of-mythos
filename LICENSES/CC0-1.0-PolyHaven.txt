Revision pinning: Poly Haven publishes file-addressed assets rather than
immutable Git tags. For these records, source_identity records the exact
asset slug, relative file path and SHA-256 of the source-file bytes; sha256
is independently checked against the repository file. This per-file
content identity is not an upstream source revision. Generated derivatives
are separately identified in client-godot/assets/external-assets.json by
generated_from and generation_note and are not represented as upstream
downloads.
